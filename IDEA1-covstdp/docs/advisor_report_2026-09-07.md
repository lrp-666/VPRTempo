## 一、研究问题

VPRTempo 是一个快速、可在线训练的脉冲神经网络（SNN）视觉场景识别系统，但它把图像展平成向量后直接进全连接网络，**完全丢失了图像的空间结构**。我的研究问题是：

> 在 VPRTempo 的脉冲编码和全连接层之间插入一个**无反向传播（BP）、无多步仿真**的卷积脉冲前端，能不能提升识别性能？如果能，增益来自哪里？

这个问题之所以值得做：SNN 视觉领域里已有很多卷积+STDP 的工作（用于物体识别），但没人把它带进 VPR 任务；已有的 VPR-SNN（包括 VPRTempo）全是全连接结构。

## 二、工作方法（先说方法论，因为它是这次工作的骨架）

为了避免"试一堆东西然后挑好看的讲"，我在动手前先写了完整的实验计划（PLAN.md），并严格遵守三条纪律：

1. **双轨评测**：每个模型变体都跑两条评测——轨 A（完整系统端到端）和轨 B（绕过读出层、直接用前端特征做最近邻检索）。这样能分清"特征好不好"和"读出层行不行"两个问题；
2. **决策门预注册**：动手前就写死"什么结果算成功、什么结果算失败、失败了往哪转"，防止事后挑数据；
3. **三档实验协议**：500 地小规模快速筛选（单 seed）→ 3300 地会议规模确认 → 3 个随机种子的正式档。中途多次证明这个协议是对的（小规模结论三次在规模下反转，详见下文）。

## 三、思路演变主线（每个转折都有实验证据驱动）

### 起点假设
加一个能学习空间特征的卷积前端应该能提升性能——这是文献里物体识别领域的标准做法。

### 转折 1：规则不是你想当然就能用的
把 BLiTNet 的 STDP 规则卷积化后，玩具测试立刻发现两个结构性问题：抑制通道因为数学约束先天死亡（发放率精确为 0）；更新规则会把核收敛成"全图均值模板"（直流塌缩）。这两个问题都被预先设计的防线测试当场抓获，修复方案（ON/OFF 双通路、中心化输入）后续都被实验证明是对的。

**小结：预先设计"失败检测器"比事后调试省了大量时间。**

### 转折 2：小规模上"学习 vs 随机"赢了，但输给了手工设计
学习规则训出来的核确实比随机核好（三个规模全正），但**手工 Gabor 滤波器组全面压制学习版**（500 地 0.984 vs 0.878）。同时核形态分析发现：学习到的核是稀疏团块/中心-外周结构，不是教科书预期的 Gabor 方向条纹。

**小结：手工先验在这个任务上非常强，"从零学习"的故事讲不通。**

### 转折 3：发现真正的瓶颈不在特征，在读出层
双轨评测显示：3300 地规模下，前端特征直接检索（轨 B）0.718，但经过原系统读出层（轨 A）只有 0.59——**读出层在丢分**，特征本身是好的。这说明原 VPRTempo 的读出机制在规模增大后成为瓶颈，这是比"加卷积前端"更大的发现。

**小结：双轨评测设计在这里收到了回报。**

### 转折 4：小规模的结论三次在规模下反转
- 池化粒度：500 地微调效果平平，3300 地成为唯一大杠杆（+12 点）；
- 放开符号约束（freesign）：500 地追平手工 Gabor（0.978），3300 地崩塌为全场最差（0.592）；
- BCM 滑动阈值：500 地无效（+0.4 点噪声内），3300 地确认档复活（+3.0 点）。

**小结：500 地小实验只能用来筛选，不能用来下结论——这条纪律救了三次。**

### 终点（当前）：手工先验 + 局部可塑性系统
最终主表（8 个变体 × 3 随机种子 × 双轨 × 双规模，48 格 + 后续 18 格补档）判定：**手工 Gabor 前端 + 原系统读出是全场最强**，3300 地比原 VPRTempo 高 12 个百分点（0.717 vs 0.597）；描述子级检索 P@100%R 达 80.2%，超 LoCS-Net（BP 训练）报告的 78.6%（协议已逐条核实，我方更严——详见第五节外部对比口径）。学习规则的价值重新定位为：BCM 滑动阈值机制能让学习路线在规模下转正（+2.3 点），且 B5+BCM 组合在最难指标上反超纯 B5。

## 五、最终格局与核心结论

3300 地会议规模、系统级指标（轨 A R@1，3 种子均值）：

```
B5 手工 Gabor 前端     0.717  ← 比基线 +12.0 点，全场最强（B5+BCM 打平且最难指标反超）
B6a Gabor初始化+微调   0.640  ← +4.3 点
B2+BCM 学习规则改进    0.620  ← +2.3 点
B2 从零学习           0.600  ← 与基线持平
B0 原 VPRTempo        0.597  ← 基线
```

**外部对比的诚实口径**（已逐条核实 LoCS-Net / VPRTempo / VPRSNN 原文协议）：描述子级检索 P@100%R 我们 80.2% > LoCS-Net（BP 训练）78.6%，且我方协议更严（3300 参考地 vs 其 3072）；但**完整系统级**我们 71.9% < 其 78.6%——这 8.3 点的差距恰好就是读出瓶颈的量化证据，也是下一步"读出适配"工作的直接动机。对导师可以这样讲：特征层面我们已超 BP 方案，系统层面的差距已定位到具体组件。

**核心结论四条**：
1. 给 VPRTempo 加卷积前端**有效**，但增益主要来自先验质量（手工设计或好的初始化），不是从零学习；
2. 学习规则在 VPR 这个任务上的可行边界已被系统性刻画：形态上学不出 Gabor（不动点问题），性能上受符号约束限制，规模是隐藏变量；
3. 读出层是原系统在规模下的瓶颈（轨 A/B 差距量化证据）；
4. 效率上所有变体保持分钟级训练（工作站 GPU 每格 2–20 分钟），手工前端甚至零训练成本。

### A.7 各变体具体做法

> 公共配置：28×28 输入、PatchNorm(7×7)、filter=8；conv 前端公共结构 C=32 通道、k=5 卷积核、local WTA 2×2（块内竞争即池化）、池化后 flatten 4608 维 → feature_layer(4608→9216) → output_layer。下游层训练（feature 层 STDP+ITP、output 层 spike-forcing 读出）所有变体完全相同，唯一变量在前端。

**B0 —— 原 VPRTempo（基线）**：无 conv 前端。图像预处理后展平成 784 维向量直接进 feature_layer（784→1568，稀疏连接，STDP+ITP，4 epoch）→ output_layer（spike forcing 监督读出）。仓库原始行为，一份不改。

**B1 —— 随机卷积冻结对照**：完整 conv 前端结构，但卷积核是随机初始化且**完全冻结**（不训练、不开 ITP、阈值保持初始值）。回答"随便加个卷积结构是不是就涨"。与 B2 同初始化分布，唯一差别是训没训。

**B1+ITP —— 冻结随机核 + 阈值自适应**：与 B1 唯一差别是开 ITP（权重仍冻结，每通道阈值按目标发放率自适应）。为 B5 提供同待遇对照，把"核来源"从 ITP 中隔离出来。

**B2 —— Conv-STDP 主组合（从零学习路线代表）**：与 B1 同结构同初始化但**完整训练**：卷积 STDP（`ΔK=η·(0.5−post)·(pre−0.5)`，只在每个 2×2 块的 winner 位置更新共享核）+ 每核保范数归一化 + 符号钳制（ON 核非负 / OFF 核非正）+ 每通道 ITP 阈值可塑性。

**B2+BCM —— 滑动阈值学习规则（锦标赛复活者）**：与 B2 唯一差别：STDP 的门控项从固定 0.5 换成**每通道滑动阈值** `θ_M ← (1−α)θ_M + α·post²`（α=0.001，慢速滑动平均）——通道越活跃阈值越高、越难再增强，自适应防止"富者愈富"。

**B5 —— 手工 Gabor 滤波器组（winner）**：卷积核**不学习**，用 32 个手工设计的 Gabor 滤波器（4 方向 × 2 频率 × 2 相位 × 2 包络尺度，5×5）。权重冻结（带符号核的负瓣完整保留），但保留 ITP 阈值自适应（实测必需：纯冻结时 25/32 通道因响应量级失配而死亡）。

**B5+BCM —— 冻结 Gabor + BCM 阈值适配**：B5 的阈值自适应机制从 ITP 换成 BCM 滑动阈值（同 B2+BCM 的 θ_M 机制）。组合格，验证"BCM 阈值机制在冻结先验上是否优于 ITP"。

**B6a —— Gabor 初始化 + STDP 微调**：16 个 Gabor 模式分解载入（每个带符号核拆成正部装 ON 通道、负部装 OFF 通道，联合响应精确等于原 Gabor），然后**不冻结**，按 B2 流程继续 STDP 训练。回答"学习在好先验上有没有增量"。

**freesign —— 放开符号钳制**：随机**带符号**初始化（不裁剪）、前向直通（关 ON/OFF 取负）、训练中允许权重自由变号（只留 ±10 防爆幅度钳）。检验"符号约束是否是性能瓶颈"的假设。

**手工动物园三格**（均为冻结+ITP，与 B5 同机制，唯一变量是核的解析形式）：
- **DoG**：高斯差分（中心-外周感受野，无方向性、无频率调谐）；
- **Log-Gabor**：对数频率域 Gabor（直流行为更好）；
- **DCT 基**：5×5 离散余弦变换基函数（**有频率覆盖但无方向选择性**——拆变量的关键对照）。

**fullBCM**：经典完整 BCM（更新量多乘一个 post 因子，φ(y)=y(y−θ_M)），与我们的简化门控版对照。

## 附录 B：实验设置与协议细节

### B.1 数据集与划分

**Nordland**（挪威铁路四季录像，VPR 标准基准）：

| 角色 | Traverse | 规模 | 说明 |
|---|---|---|---|
| 参考集（训练+数据库） | spring + fall | 500 地（迭代档）/ 3300 地（正式判定，3 模块×1100） | 两季节图像合并为一个参考库（location_repeat=2 机制） |
| 查询集 | summer | 500 / 2700（3300 地口径省略前 600 地，与 VPRTempo 论文一致） | 季节跨度最大的查询（春/秋→夏） |

采样与预处理：每 8 帧取 1 帧（filter=8）；灰度 → 自适应 gamma 校正 → 缩放 28×28 → 局部块归一化（7×7 窗口 Z-score）→ 幅度脉冲编码（像素/255 ∈ [0,1]）。

**Oxford RobotCar**（450 地 sun,rain→dusk 子集）：计划内，用于第二数据集复核（S3.5）。

### B.2 随机种子与可复现性

- 正式档全部 **3 个种子 {0, 1, 2}**，报 mean±std；
- 种子固定范围：torch/numpy/random 三件套 + DataLoader shuffle 生成器 + worker_init_fn + PYTHONHASHSEED——网络初始化与数据顺序均可复现（B0 默认路径做过逐比特回归验证）；
- B1（随机核）与 B2（学习核）同种子共享同一随机初始化，唯一变量是"训没训"；
- 单 seed 的迭代/确认档数字只作筛选参考，不进正文结论。

### B.3 评测指标与 GT

- GT：单位矩阵（地点 i 查询匹配地点 i），零容差，与 VPRTempo 论文口径一致；
- 主指标：Recall@1/5/10/25（VPRTempo 口径）；
- 互补指标：R@100%P（零误报下的召回，VPRSNN 口径）与 P@100%R（零漏报下的精确率，LoCS-Net 口径）——两个方向都报，因为外部工作口径不一；
- 双轨：轨 A = 完整系统（含 spike-forcing 读出层）；轨 B = 前端特征直接余弦最近邻（隔离 encoder 质量）。

### B.4 训练超参（关键值）

conv 前端：conv_epoch=4、η_STDP=0.01、η_ITP=0.15、阈值初始 U[0,0.5]、目标发放率 [0.2,0.9] 线性分配、WTA 块 2×2、winner 聚合 mean、pre 中心化（pre−0.5）。
下游层：与 VPRTempo 论文表 I 完全一致（feature 层 η_STDP=0.005、η_ITP=0.15、4 epoch；output 层 spike forcing）。
学习率退火 (1−t/T)²，T 按层独立计算。

### B.5 计算环境

工作站容器：RTX 4090 + 4090 D（各 24GB），PyTorch 2.10.0 + CUDA；pixi 环境锁文件保证依赖可复现；CPU/GPU 结果一致性已验证（±1 点内）。训练耗时：500 地每格 ~35–115s（GPU），3300 地每格 ~10–20 分钟；主表 48 格总墙钟约 5 小时（双卡并行）。

### B.6 与已有工作的协议对比（逐条核实原文）

| 项 | LoCS-Net (2025) | VPRTempo (ICRA 2024) | VPRSNN (RA-L 2022) | 本文 |
|---|---|---|---|---|
| 参考/查询 traverse | spring+fall / summer | 同左 | 同左 | 同左 ✓ |
| 采样率 | 每 8 帧 | 每 8 秒 | 每 8 秒（取前 1/4 段） | 每 8 秒 ✓ |
| 参考地点数 | 3,072 | 3,300 | 100 地分段 | 3,300 ✓ |
| 查询数 | 3,072（无 skip） | 2,700（省略前 20%） | 每段 100 | 2,700 ✓ |
| GT 容差 | 精确匹配 | 精确匹配 | 精确匹配 | 零容差 ✓ |
| 主指标 | P@100%R | R@N | R@100%P | 三种全报 ✓ |
| 输入分辨率 | 56×56 | 28×28 | 28×28 | 28×28 ✓ |
| 训练方式 | BP（ANN-to-SNN 转换） | 无 BP 局部规则 | 无 BP | 无 BP ✓ |

**可比性结论**：描述子级（轨 B）数字可与 LoCS-Net 直接比且我方协议更严（参考集更大）；系统级对比需注意其查询集不省略前段。VPRSNN 口径差异大，只作历史引用。
