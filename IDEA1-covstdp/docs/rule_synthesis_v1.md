## 1. 三份报告的共识（跨三个独立 AI 调研，权重最高的结论）

1. **团块而非 Gabor 的根因不在规则，主要在输入统计与竞争结构**（三份一致，Opus 引 Brito & Gerstner 2016 最明确）：任何 Hebb+归一化家族在未白化的自然图像上先逼近 PCA 主成分——第一主成分是 DC、其次是低频各向同性结构 → 中心-外周团块。**只换规则不换输入/竞争结构，大概率仍是团块。**
2. **Gabor 形态三条件**（Opus 报告明确列出）：(A) 输入去 1/f 二阶相关（DoG/ZCA 白化）；(B) 权重能表达带符号模式（ON/OFF 或 free-sign）；(C) 规则对高阶统计敏感或有去相关机制。
3. **BCM 滑动阈值替换固定 0.5**：三份全部推荐（两份列为首选/次选，一份列为方案 B）。理论引用最硬（BCM 1982 + Intrator & Cooper 1992 投影追踪等价 + triplet STDP↔BCM 桥梁 + Shouval 1997 方向选择性）。
4. **(0.5−post) 是"去选择性"的定点稳态器**（三份一致）：越赢越被拉回 0.5，不促进通道间分工——这是 B2 弱于 freesign 的机制解释之一。
5. **侧向 anti-Hebbian 去相关"最对症"但工程成本最高**；KH 名次规则是廉价替代（runner-up 负更新即单层的侧向去相关特例）。
6. **SoftHebb 接口最干净但不解决方向选择性**（文献第一层仍是 Gabor/blob 混合），优先级降。
7. **Triplet STDP 不用做**：幅度域极限退化为 BCM。
8. **"Gabor 初始化 + 局部规则微调"是文献空位**（三份一致，Opus 给出警告：规则不动点若非 Gabor，会主动漂离——需先跑不动点漂移测试）。这是论文卖点的候选位。

## 3. 选定方案：B7 候选规则（自提规则的论文卖点）

**名称（暂定）**：**Rank-BCM 规则** —— 单步幅度域、滑动阈值、名次调制的竞争 Hebbian 规则。

```
ΔK_c = η · sign_rank · (θ_M,c − post) · (pre − 0.5) · Θ(post)

θ_M,c ← (1−α)·θ_M,c + α·post_c²        # 每通道滑动阈值（BCM），替换固定 0.5
sign_rank：块内跨通道名次——winner 通道 +1，第 k 名通道 −δ（KH 式 runner-up 反推，廉价去相关）
```

与现有管线的差异只有两处手术（改动小、可开关、可消融）：
1. 固定 0.5 → 每通道滑动阈值 θ_M（BCM 化）；
2. 纯 winner 更新 → winner +1 / 第 k 名 −δ（跨通道名次反推）。

**保留不动**：pre 中心化（直流防线实证有效）、保范数 L1、ITP、WTA、clamp[0,0.9]、conv2d_weight 向量化路径。

**卖点叙事**：这不是"BLiTNet 规则的卷积化"，而是"针对 VPR 检索任务设计的单步竞争可塑性规则"——BCM 给选择性锐化（理论 44 年）、名次反推给通道分工（KH 2019）、全部无多步仿真无 BP。每个组件都有硬引用，组合是新的。

**风险预案**：α（θ_M 滑动速率）必须慢于权重学习 10–50×，否则与 ITP 双反馈回路振荡（Sonnet 报告明确警告）；初值 θ_M=0.25（=0.5²，与现规则不动点兼容）。

## 4. 实验设计（迭代档：500 地 seed0 轨 B，GPU 每格 ~2min）

| 格 | 配置 | 回答的问题 |
|---|---|---|
| E1 | B2 + 仅 BCM 化（θ_M 替换 0.5） | 滑动阈值单独值多少？ |
| E2 | B2 + 仅名次反推（δ=0.4, k=2） | 跨通道去相关单独值多少？ |
| E3 | **B7 = E1+E2 复合** | 完整规则值多少？ |
| 对照 | B2 0.878 / freesign 0.978 / B5 0.984（已有，同口径 block2） | 判定基准 |

**预注册判据**（写死再跑）：
- **B7 主判据**：轨 B R@1 > B2 + 2 点（超迭代档噪声）且 ≤ freesign 是可以接受的——**若 B7（符号约束 ON/OFF 版）能逼近 freesign，则故事是"规则设计弥补了符号约束的代价"**，最强叙事；
- 形态判据：B7 核的 R²/方向合成长度应 ≥ B2（不要求到 B5 水平，团块→条状的部分转变即是机制证据）；
- 每格必须过玩具测试断言（DC/AC 下降、核间余弦不升、范数稳定）+ 诊断 JSON（θ_M 曲线、发放率）。

**若 E1/E2/E3 全部无效**（≤ B2）：退回分析型叙事，"BCM/名次机制在单步幅度域无效"本身是可写的负面结果；现有 freesign 证据链不受影响。
