## 2. 训后核 Gabor 拟合 R²（`results/s210_b6_kernel_diag.json`）

B6a 在 16 个 ON/OFF 联合核（J = w_on + w_off）上拟合；其余组直接拟合 32 核。
拟合模块复用 viz_kernels.py（torch LBFGS，8 确定性起点）。

| 组 | R² 中位数 | IQR | 拟合成功（R²>0.5） | 说明 |
|---|---|---|---|---|
| B5 手工组（sanity） | 1.000 | 0.000 | 32/32 | 确定性参照 |
| B6a 训后 | **0.979** | 0.027 | 16/16 | **条纹保留**，θ 四方向齐全（≈0/45/90/135°） |
| B6b 训后 | **0.978** | 0.044 | 32/32 | **条纹保留**（同上） |
| freesign 训后 | 0.449 | 0.109 | 10/32 | 放开钳制**没有**从零学出条纹 |
| B2 训后（对照） | 0.437 | 0.148 | 9/32 | 与 S3.1 结论一致 |
| B1 随机（对照） | 0.416 | 0.137 | 12/32 | 随机基线 |

**R² 结论：B6a/B6b 训后条纹都保留（没有被洗掉）**，R² 中位数 ≈0.98，四方向覆盖完好。
**机制回答（S3.3-8）：free-sign 随机初始化仍学不出条纹（R² 0.449 ≈ B2 的 0.437，
拟合成功 10/32 ≈ B2 的 9/32）——按卡片的预注册解读，"符号约束 ⇒ 无条纹"假设
被否：根因在规则本身（不动点形态），不在符号钳制。但注意 free-sign 轨 B
大幅升至 0.978（≈B5 的 0.984）——符号约束虽不是条纹缺失的根因，却是检索
性能的重要限制因素（增益不经过 Gabor 形态通道，见 §3）。**

## 3. DC/AC 曲线与 §8 诊断（`results/s210_b6_dcac_curves.json`，诊断性重放）

每 25 步快照，2000 步（500 图 × conv_epoch 2）。DC/AC = |mean(K)|/(std(K)+ε)。

| exp | DC/AC 初→末 | pre-WTA 发放率 初→末 | thr 均值 初→末 | 核间余弦 初→末 |
|---|---|---|---|---|
| b2_500_block2 | 3.122 → 0.987（下降 ✓ centered 防线成立） | 0.877 → 0.502 | 0.306 → 0.471 | −0.029 → −0.018 |
| b6a_500 | 0.000 → 0.000（零均值全程保持） | 0.485 → 0.521 | 0.247 → 0.230 | 0.025 → 0.044 |
| b6b_500 | 0.001 → **0.265**（DC 爬升） | **0.048 → 0.033**（极低且下降） | 0.182 → **0.000**（触底） | 0.045 → 0.112 |
| freesign_500 | 0.146 → 0.194 | 0.111 → 0.110 | 0.193 → **0.002**（触底） | 0.005 → 0.079 |

**B6b 的病不在核形态（R² 0.978）而在工作点**：free-sign 直通前向下，带符号核
对非负输入只有正半响应可过 clamp(min=0)，可达到的发放率上限结构性偏低
（≈3–5%）；ITP 为追目标发放率把阈值推到 0 触底（clamp(min=0)）后失效，
阈值地板卡死 → 通道有效稀疏度过高 → 轨 B 掉到 0.712、轨 A 读出崩塌（0.130）。
伴随 DC/AC 0.001→0.265：free-sign 下 STDP 往核里堆直流（无符号约束时
centered pre-term 的直流防线不再对称起效）。

**freesign 同样 thr 触底（0.002）但发放率稳在 0.110，轨 B 0.978 ≈ B5**——
注意其核并非条纹状（R² 0.449），增益不经过 Gabor 形态通道。

## 4. 预注册解读对位（S2.10 卡片，供母会话判定，本文件不下结论）

- B6a 0.936 < B5 0.984（同口径 block2）：落在"B6 < B5 → 规则破坏好先验"
  与"B6 ≈ B5"之间的判读留给母会话（差 4.8 点，单 seed）。
- B6a > B2（0.936 vs 0.878）：手工先验 + STDP 微调后仍优于从零学习。
- B5 的 block2 口径（0.984）显著高于 S2.9 存档的 block4 口径（0.906）——
  池化粒度对冻结 Gabor 前端同样是大杠杆。
- 验收断言 5/5 通过（experiments/test_b6_gabor_stdp.py）：分解一致性
  max diff 8.2e-08（atol 1e-6）；16 模式四方向覆盖；free-sign 训后出现负值
  且非 free-sign 回归无越界；B6a 训 50 步 ON/OFF 对 cos(J,G) min=0.999；
  B0 smoke100 回归 R@1=0.99 不变。

## 5. 已知坑 / 后续建议（交母会话）

1. B6b 若要让"signed Gabor + free-sign 训练"成为公平对照，需要先解决阈值
   地板问题（如允许 thr<0 或改 free-sign 的 ITP 目标发放率），否则它测的是
   "工作点崩塌"而非"放开钳制的学习增量"。
2. free-sign 初始化同步放开了符号裁剪（N(0,1/6) 带符号）——否则抑制通道
   在直通前向下对非负输入恒 ≤0，永久性死通道。此为本实现的显式设计决策，
   与 PLAN 文本的"随机初始化"有细微出入，已记录待母会话确认。
3. 数字均为单 seed 迭代档；进主表需 3 seeds 与 3300 地判定档（S3.2 程序）。
