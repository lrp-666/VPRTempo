# 时间预算（S1.5 耗时外推）

日期：2026-09-02｜测量基准：本机 CPU-only，B0 单格 = 训练 ~158s + 轨A评估 ~2.4s + 轨B评估 ~9s ≈ **170s**

## 单格成本假设

| 变体 | 单格估计 | 依据 |
|---|---|---|
| B0（无前端） | 170s | 实测 |
| B1 / B5（冻结前端） | ~200s | 比 B0 多 conv 前向（无 conv 训练），粗估 +30s |
| B2（Conv-STDP 1层） | ~400s（估） | 多 conv 训练 2 epoch × 1000 图；conv2d + WTA + 更新的实测成本待阶段 2 测量，此处按 ~2× B0 保守估 |
| B3（2层） | ~600s（估） | 2 个 conv 层依次训练 |
| B4（CNN+BP） | ~300s（估） | GPU 上更快；CPU 也可承受 |

## 全实验矩阵外推（本地 CPU）

| 实验 | 格子数 | 估计总耗时 |
|---|---|---|
| 主表（B0–B5 × 3 seeds × 双轨） | 6×3=18 | ~18 × 300s ≈ 1.5–2 h |
| Table 2（WTA×聚合 6 格 × 3 seeds） | 18 | ~2 h |
| Table 3（PatchNorm 2×4 × 3 seeds） | 24（其中 B0 列 6 格已有） | ~2.5 h |
| Table 3b（2×2 × 3 seeds） | 12 | ~1.5 h |
| C×k 组合（6–9 组 × 3 seeds，轨 B 优先） | ~24 | ~2 h |
| **阶段 3 主实验合计（CPU）** | | **~10 h 量级** |

## 结论与分工建议

- **阶段 1 全部本地完成**（实际 6 格 ≈ 16 min）。
- 阶段 2 的开发与玩具测试本地进行；阶段 3 主矩阵本地 CPU 也可一夜跑完，**工作站 GPU 作为加速选项而非必需**（conv 训练实测后更新本表）。
- 效率表（实验 1.5）要求同硬件对比：正式数据统一在一个平台采集（建议工作站 GPU，本地数字仅作开发参考）。
